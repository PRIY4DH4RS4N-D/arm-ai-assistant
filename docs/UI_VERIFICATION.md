# UI verification

The Compose interface uses native drawing for the EMBER orb, with independent ribbon, rim, light and particle motion. It uses real microphone, model and Tutor states where available. Cinematic and orb motion respect the Android animator setting and pause with the lifecycle.

The [physical-device captures](ui-verification/) show the application, including the introduction, learning flow and bundled OCR result. Only the Android notification strip was cropped from the new captures.
