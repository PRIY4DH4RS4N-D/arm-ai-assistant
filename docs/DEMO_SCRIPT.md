# Two-minute EMBER phone demonstration

Open with the replayable introduction and Home orb. Show the learner's active interest and open an ARM Architecture topic in Explore. Return to the existing Algebra learning plan. Send a fresh question to the local Tutor, show the generated response, then generate and answer an Algebra quiz. Show local answer feedback and the saved progress graph. Close on EMBER Home.

The device is a realme P4 Pro 5G, RMX5116, ARM64, Android 16. The capture runs in airplane mode with Wi-Fi and mobile data off. The recording uses actual phone frames and captions to identify the device and learning flow. [MP4](../submission/demo/EMBER_PS4_DEMO_120S.mp4)
