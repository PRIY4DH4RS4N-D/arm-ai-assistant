# Privacy and security

Learner records and scans are app-private and scoped to a local profile. Profile deletion cascades through the Room learning records. The manifest disables application backup and removes INTERNET. Android provides individual camera file access and document access. The model importer uses manifest validation, checksum verification and staging before activation.

Imported text is treated as study material. Generated text cannot execute code or write authoritative mastery. The coding workspace checks pre-authored traces in Kotlin. Device-level access controls protect the app sandbox. Local profile selection provides no separate PIN or biometric authentication. A full data export and audit of device speech provider behaviour remain open.
