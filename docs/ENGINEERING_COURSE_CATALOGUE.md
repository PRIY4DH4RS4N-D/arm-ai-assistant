# Engineering course catalogue

The [local catalogue](../app/src/main/java/com/example/adapt_ai_ui/data/platform/LearningCatalog.kt) includes ARM fundamentals, AArch64 assembly, AAPCS64, exceptions and interrupts, memory ordering, NEON and processor performance. Computer Architecture covers datapaths, pipelines and memory hierarchy. Digital Electronics includes Boolean algebra, combinational and sequential logic, timing and finite-state machines. Additional tracks cover VLSI, FPGA, embedded systems, data structures, algorithms and operating systems.

Search across titles and concepts, save interests, or create topics on the device. Topic suggestions and generated lessons should be reviewed against authoritative sources. The independently checked quiz demonstration uses Algebra.
