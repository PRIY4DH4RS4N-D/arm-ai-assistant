# Camera OCR

Scan & Learn opens the system camera through a one-file URI grant or imports a local image through Android's document picker. It bounds the decoded image, supports rotation and edge trimming, and uses ML Kit's bundled Latin recognizer. The learner can edit extracted text, save the scaled original and text to their local profile, or send a bounded excerpt to the offline Tutor.

On RMX5116 in airplane mode with Wi-Fi and mobile data off, a 1220 x 740 printed fixture produced all four expected lines. The application reported 389 ms for this single observation. Save and reopen succeeded. Handwriting, equation semantics, broad recognition accuracy and physical camera capture need further validation. [Bundled recognizer documentation](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)
