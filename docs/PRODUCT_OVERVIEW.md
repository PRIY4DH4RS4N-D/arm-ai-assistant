# EMBER product overview

EMBER is a local learning assistant for PS4. Learners choose a topic and goal, get a weekly study plan, ask a local Llama tutor, practise and revisit assessed weaknesses. Each learner has separate notes, conversations and activity.

The introduction runs on first launch and can be replayed in Profile Settings. Profile also opens coding exercises, Scan & Learn, study activity and Model Management. See the [user entry points](../README.md) and [completion matrix](COMPLETION_MATRIX.md).
